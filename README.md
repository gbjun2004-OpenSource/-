# 개발 목적
-----
2025년 2학기 오픈소스개발과활용 기말 과제로 제시된 "블로그 만들기"를 위한 깃허브 리포지토리입니다.

# 개발 주제
-----
팀원들과의 주제 회의를 통해 "안산시의 행정구역별로 방문할 만한 관광지와 식당 소개하기"로 결정되었습니다.

# 개발 인원
-----
+ 권범준 - 팀장 & 사동 소개 페이지 작성
+ 김규현 - 고잔동 소개 페이지 작성
+ 김동하 - 중앙동 소개 페이지 작성
+ 문유빈 - 대부동 소개 페이지 작성

# 개발 기간
-----
2025 / 12 / 01 ~ 2025 / 12 / 13

# 개발 기록
1. 첫 대면회의 : 원격 저장소 생성 및 로컬 저장소와 연동, 시도 중 문제 발생 후 재생성
2. 첫 주 : 도메인 및 각 행정구역별 소개 페이지 작성
3. 둘째 주 : 각자의 진행상황 공유, 수정사항 및 제안사항 공유.
4. 12/13 : 각자의 브랜치 병합 후 최종 수정을 진행했으나, 각자의 커밋 기록이 달라지는 문제 발생 -> 이름 변경, 로컬 저장소 삭제 후 재생성 등 여러 방법을 시도해 보았으나 실패, 연결되지 않는 파일들은 파일 그대로 제출하기로 결정
